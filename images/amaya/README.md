# Amaya Hotel & Luxury Suites photos

Drop photos into this folder using these exact file names. They appear on the
case study page (`work.html`) automatically; until then a dashed placeholder shows.

| File name      | Where it shows                     |
|----------------|------------------------------------|
| `hero.jpg`     | Main case study image (left panel) |
| `suite.jpg`    | Gallery: Luxury suite (wide)       |
| `exterior.jpg` | Gallery: Exterior                  |
| `pool.jpg`     | Gallery: Pool & outdoor spaces     |
| `dining.jpg`   | Gallery: Dining (wide)             |
| `bathroom.jpg` | Gallery: Bathroom details          |
| `lobby.jpg`    | Gallery: Lobby & lounge            |

Tips: landscape photos about 1600px wide, saved as JPG under ~400 KB each, keep pages fast.
